# ShoppingList-Go
Trying out the Bubbletea framework (https://github.com/charmbracelet/bubbletea) and the whole Ecosystem around it.
This is just an small side CLI Project q-q for learning Go (Golang).

## Added Features
- Parsing the  List to an MD File -> Also Updating it based on the Actions made in the CLI
- User I/O
- Deleting Items of the List
- Switching between Appending and Listing View/Mode
